# FinOps controls

Mandatory tags: Project, Environment, Owner, CostCenter, ManagedBy and DataClassification. Review EKS requests/limits, Karpenter consolidation, NAT/data-transfer spend, Aurora sizing, S3 lifecycle and log retention monthly. Configure AWS Budgets and Cost Anomaly Detection in the billing/shared-services account. Cost optimization must not weaken availability, retention, security or compliance requirements.

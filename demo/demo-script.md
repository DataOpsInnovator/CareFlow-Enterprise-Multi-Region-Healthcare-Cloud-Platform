# 15-Minute Demo

Show the regional topology and trust boundaries.

## 1:30–3:00 Developer Experience
Show the golden path and repository template.

Run PR validation, security checks, SBOM, and image signing.

## 5:00–7:00 Canary
Deploy a deliberately failing version and demonstrate rollback.

Terminate a pod/node in a controlled environment and show recovery.

## 9:00–11:00 DR
Execute the approved regional recovery runbook with synthetic traffic.

## 11:00–12:30 Policy
Show rejection of an invalid/privileged workload.

## 12:30–14:00 AI Operations
Show evidence-backed incident summarization.

## 14:00–15:00 FinOps
Show budget controls and teardown workflow.
